# Support

## Documentation first

Most questions are answered in the docs already:

- [README.md](README.md) — setup, tool reference, configuration
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — how it's built
- [docs/releases/KNOWN_LIMITATIONS.md](docs/releases/KNOWN_LIMITATIONS.md) — verified, current
  limitations (check here before filing a bug that might already be a known/accepted tradeoff)
- [docs/adr/](docs/adr/) — why specific design decisions were made

## Getting help

Open a [GitHub issue](https://github.com/Ahmed-Eldamanhoury/Delegate-MCP/issues) for bugs,
questions, or feature requests. There is no other support channel (no chat, no forum, no paid
support) — this is a single-maintainer project, so response time isn't guaranteed.

## Security issues

Do not use a public issue for a security report — see [SECURITY.md](SECURITY.md).
